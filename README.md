# 행복한 책읽기 원고 작업실

"행복한 책읽기" 프로그램은 매주 책 한 권을 소개합니다. 이 저장소는 그 프로그램의 **오프닝·중간 내레이션·엔딩 원고를 AI 에이전트(Claude)에게 맡겨 만들어 보는 연습 공간**입니다.
과학기술정책대학원 「신흥기술영향세미나」 수업 실습으로 만들었습니다.

### 40초 소개 영상

![행복한 책읽기 원고 작업실 소개 영상: 왜 만들었는지, 입력(raw/) → 규칙(CLAUDE.md) → 결과(out/) → 사람의 직접 확인 순서로 작동하는 모습](assets/intro.gif)

## 왜 만들었나요?

원고 한 편을 손으로 쓰면 약 **3시간 20분**이 걸렸습니다. 대부분은 책을 읽는 시간이고, 나머지는 줄거리를 파악하고 원고를 쓰는 시간입니다.
이 저장소에서는 그 시간을 줄일 수 있는지 시험합니다. 대신 원고의 형식과 정확성은 지켜야 합니다.
불편을 처음 정리한 기록은 [01_페인포인트.md](01_페인포인트.md)에 있습니다.

## 폴더 둘러보기

```
나의_3주차/
├── README.md               ← 지금 읽고 있는 안내서
├── CLAUDE.md               ← 에이전트에게 주는 작업 규칙
├── 01_페인포인트.md        ← 해결하려는 불편과 성공 기준
├── 5주차_기록.md           ← 수업 과제 기록 (맡기기 전 예상과 실제 결과)
├── 기록.md                 ← 작업 날짜별 한 줄 기록
├── assets/
│   └── intro.gif           ← 이 README 맨 위의 소개 영상
├── raw/                    ← 입력 자료 (읽기만 함)
│   └── 예시_주간원고.md    ← 형식 예시. 실습용으로 지어낸 책
└── out/                    ← 완성된 원고 (책 한 권당 파일 하나)
    ├── 바다를_건넌_씨앗들_원고.md
    └── 팩트풀니스.md
```

## 어떻게 작동하나요?

1. **입력 넣기**: `raw/`에 책 정보, 줄거리 요약, 핵심 메시지를 넣습니다. 형식은 `raw/예시_주간원고.md`를 따릅니다.
2. **맡기기**: 에이전트가 [CLAUDE.md](CLAUDE.md)의 규칙에 따라 원고를 씁니다.
3. **결과 받기**: `out/`에 책 한 권당 `.md` 파일 하나가 생깁니다.
4. **직접 확인하기**: 에이전트의 설명만 믿지 않습니다. 바뀐 내용(diff)을 사람이 직접 읽고 받아들일지 정합니다.

## 원고 규칙

| 원고 | 규칙 |
|---|---|
| 오프닝 | **질문으로 시작**하고, 책이 다루는 핵심을 소개함 |
| 중간 내레이션 | 오프닝·엔딩에 **담지 못한 내용**을 보충함 (예시는 2개) |
| 엔딩 | 핵심 메시지를 정리하고, **의미를 묻는 질문**을 던진 뒤 진행자 맺음말로 끝냄 |

원고를 확인할 때는 아래를 봅니다.

- [ ] 세 원고(오프닝·중간 내레이션·엔딩)가 모두 있는가?
- [ ] 세 원고 모두 핵심 메시지를 담았는가?
- [ ] 중간 내레이션이 오프닝·엔딩과 겹치지 않는가?
- [ ] 줄거리 요약에 없는 사실을 지어내지 않았는가?

## 읽을 때 알아 두세요

- **`raw/예시_주간원고.md`와 그 원고는 지어낸 예시입니다.** 「바다를 건넌 씨앗들」과 "가상저자 A"는 실제로 있는 책이나 사람이 아닙니다.
- **`out/팩트풀니스.md`는 아직 방송 전 확인이 필요한 초안입니다.** `raw/`에 입력 자료가 없는 상태에서 일반적으로 알려진 책 내용으로 썼습니다. 그래서 수치나 번역 명칭은 책 원문으로 다시 확인해야 합니다. 확인할 항목은 그 파일 맨 아래 〔확인 필요〕에 적혀 있습니다.
- 원고는 책을 직접 요약하고 새로 쓴 글이며, 책 본문을 옮겨 적지 않았습니다.

## 개인정보와 보안

공개 저장소라서 [.gitignore](.gitignore)로 아래 파일이 올라가지 않게 막아 두었습니다.

- `.env` 같은 비밀값 파일 (API 키, 비밀번호)
- `raw/private/` 폴더와 파일 이름에 "개인정보"가 들어간 파일
- PDF 파일과 프로그램 임시 파일
- 이 컴퓨터에서만 쓰는 Claude 설정 (`.claude/settings.local.json`)

실제 개인정보가 든 자료를 써야 한다면 `raw/private/`에 넣어 주세요. 학번·연락처 같은 제출자 정보는 이 저장소가 아니라 LMS 제출란에 적습니다.
